# 《江山北望》隐藏判定复核与结局路由

核查日期：2026-11-12。适用本机已安装 build 21189939，不代表待更新版本。仅检查本地安装资源与客户端代码，未引用外部攻略，未调用游戏服务器、修改存档或实机验证结局。

## 本次结论

先前“本地流程图没有隐藏判定”的表述范围过大。准确说法是：**已检查的八张 SVG 没有判定表达式；客户端其他文件确实保存了一部分数值提示与触发逻辑。实际选择后的剧情时间线由 API 返回，完整隐藏条件尚未恢复。**

复核覆盖八张 SVG 的全部属性、渲染与连线筛选代码、游戏状态与选择提交代码、播放器提示表、视频映射表，以及 49 个 pack 的条目类型。pack 中发现字幕、影音、图片和系统元数据，没有发现独立脚本或规则表。app.asar 内未发现 source map；不能据此推断运行缓存或服务器也没有规则。

## 如何看每个结局的路径

打开同目录 `结局路由查看器.html`，无需联网或启动游戏。

1. 在左侧搜索结局，或按章节筛选。另有虞宫同意、存活、处决三个快捷入口。
2. 上方显示从本章入口到该结果的完整路由网络，包括所有相关分支与合流。下方可按编号查看每一条完整路径，无最短路径筛选或前 N 条截断。
3. “逐级反查”从结果往回展开全部前驱，可检查不同来源分支，直到本章入口；遇到缺线会提示。
4. “全部上游连线”列出所有可能上游，包含原图孤立片段，并标注入口可达性。
5. 路径中的绿色提示来自本地数值提示表；黄色提示表示分岔的条件未收录，不能直接当攻略。

所有组合路径都纳入计数与编号访问，用有向无环图无损表示，并按编号展开单条路径，避免一次渲染十万余条重复列表。59 个结局合计 142,138 条本章图上组合路径；其中部分可能被隐藏状态排除。

## 提取修正与覆盖

- 旧索引 768 条连线；按客户端解析规则复核后为 **770 条唯一连线、615 个资源节点、59 个结局**。
- 补回 `a01_a053_a012A,a01_a053_a012A_HE`：原脚本只接受数字开头的 ID，漏掉这种格式。
- 补回 `06_042_009LOOP,06_043_009A,`：原属性末尾多一个逗号，按客户端 `split(',', 2)` 取前两段。
- 59/59 个结局都有本章入口至终点的图上路径；这只证明连通性。
- 13 个结局含内置 `help` 提示，有些明确涉及前章选择。这说明只看当前章节图不足以恢复完整路线。
- 某些结局 ID 与视频表 storylet ID 不一致；查看器保留映射状态。没有凭名称相似强行合并。
- 章节之间没有擅自添加连接边，也没有补造皇帝信任、忠诚、军心等隐藏条件。
